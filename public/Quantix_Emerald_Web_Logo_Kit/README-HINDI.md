# Quantix Emerald Website Logo Kit

Theme colors: #00a69c, #00c2b6, #00877f, #171717.

Included: full navbar logo with tagline, compact sticky/mobile logo, dark/light footer variants, favicon ICO/PNG/SVG, Apple/Android/PWA icons, social preview images, PNG/WebP sizes, React TypeScript component, CSS, manifest and head tags.

Recommended: desktop before scroll = full logo 46–54px height; scrolled/tablet/mobile = compact logo 34–42px; favicon = icon only; footer = full logo. Do not apply CSS transform:scale() to the logo.

Quality note: source is an AI-generated raster concept. Assets are high-resolution for normal website use, but included SVGs are raster-backed wrappers, not editable true-vector artwork.
